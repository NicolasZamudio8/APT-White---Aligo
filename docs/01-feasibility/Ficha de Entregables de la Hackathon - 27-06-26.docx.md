Indique las **arquitecturas, lenguajes** y **tecnologías** utilizadas, especificando las **funcionalidades** que la hacen sobresalir de entre las demás soluciones propuestas.A | **Nuestra solución** resuelve el reto de manera integral mediante el desarrollo de una plataforma C2 de grado de simulación adversaria. Se utiliza un backend en **Python (FastAPI)** junto con el ORM **SQLAlchemy 2.0** conectado a una base de datos relacional serverless **Neon PostgreSQL** que persiste de extremo a extremo todas las interacciones del operador (agentes, redirectores, llaves, ejecuciones, logs). El frontend se desarrolló en **React (TypeScript)** utilizando un sistema de diseño modular en Vanilla CSS para lograr una interfaz altamente fluida e interactiva. <br><br> **Funcionalidades Destacadas:** <br> 1. *Mapa Táctico Interactivo (D3.js)* que geolocaliza y visualiza en tiempo real a los 33 agentes de los departamentos de Colombia con indicadores dinámicos de estado y pings. <br> 2. *Persistencia completa de la consola de red TShark* en base de datos PostgreSQL, garantizando que el análisis forense de paquetes no se pierda al recargar la página. <br> 3. *Gestión Distributiva de Red*: Asignación interactiva de redirectores y encadenamiento de proxies (Uplink parent) para simulación realista de tráfico evasivo. <br> 4. *Seguridad Dinámica*: Rotación interactiva de claves simétricas XOR/AES asignadas individualmente por agente. <br> 5. *Asistente Copilot de Ciberseguridad* integrado a través de la API de **Google Gemini (gemini-3.5-flash)** para la traducción de intenciones a comandos, análisis forense de logs y alertas preventivas ante inyecciones destructivas (Guardrails). |  |  |  |
