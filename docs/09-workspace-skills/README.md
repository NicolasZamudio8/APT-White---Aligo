# Workspace Skills Propuestas

Para acelerar el desarrollo del C2 en esta hackathon, se proponen las siguientes Workspace Skills para los agentes de IA (Gemini/Claude) que nos asistan.

1. **c2-agent-builder**: Skill especializada en escribir scripts en Python usando WebSockets con librerías nativas (syncio), con foco en evasión y empaquetado (PyInstaller) sin depender de librerías externas voluminosas.
2. **astapi-wss-architect**: Skill especializada en crear endpoints asíncronos en FastAPI (sync def), inyectar conexiones a PostgreSQL (Neon) y manejar miles de conexiones WebSocket simultáneas manejando buffers y latencias.
3. **gemini-prompt-engineer**: Skill enfocada en diseñar el 'System Prompt' perfecto para la API de Gemini, estructurando los comandos en formato JSON y previniendo alucinaciones cuando la IA deba traducir texto a comandos Shell.
